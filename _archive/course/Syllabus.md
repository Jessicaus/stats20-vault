## Policies worth remembering

- **Academic integrity agreement** goes with HW 1. If it's missing by the end of the quarter, you get an F in the course.
- **AI policy:** no generative AI unless an assignment explicitly allows it. When it's allowed, you must acknowledge it and include an appendix showing what was generated. Unacknowledged AI use earns a 0 until fixed.
- Code must be **commented**. Readable, reproducible code is valued over clever or short code.
- Submit through Bruin Learn only (no email submissions). Use your UCLA email.
